# 京东价格监控应用

一个用于监控京东商品价格变化的Android应用，支持自定义目标价格、邮件和微信提醒功能。

## 功能特点

- 📱 **商品管理**：添加、编辑、删除监控商品
- 💰 **价格监控**：自动检查商品价格变化
- 🔔 **价格提醒**：当价格达到目标时发送通知
- 📧 **邮件通知**：支持QQ邮箱价格提醒
- 💬 **微信通知**：支持微信消息推送
- ⏰ **定时监控**：每2小时自动检查一次价格
- 🎯 **自定义目标价格**：设置个人期望的价格

## 技术栈

- **开发语言**: Kotlin
- **架构模式**: MVVM
- **数据库**: Room
- **网络请求**: Retrofit + OkHttp
- **异步处理**: Coroutines
- **定时任务**: WorkManager
- **UI组件**: Material Design 3

## 主要组件

### 1. 数据模型 (Product)
- 商品ID、名称、链接
- 当前价格、目标价格
- 通知设置、邮箱地址
- 监控状态、时间戳

### 2. 数据库 (Room)
- 商品信息的增删改查
- 价格历史记录
- 通知设置管理

### 3. 网络请求 (Retrofit + OkHttp)
- 获取京东商品价格
- 随机User-Agent避免检测
- 异常处理和重试机制

### 4. 定时任务 (WorkManager)
- 每2小时自动检查价格
- 网络约束和电池优化
- 手动启动/停止监控

### 5. 通知系统
- 本地通知提醒
- 邮件通知（QQ邮箱）
- 微信通知（需要额外配置）

## 使用方法

### 1. 添加商品
1. 点击主界面右下角的"+"按钮
2. 输入商品名称和链接
3. 设置目标价格
4. 配置通知方式（邮箱/微信）
5. 保存商品

### 2. 监控价格
- 系统会自动每2小时检查一次价格
- 可以手动点击"立即检查价格"按钮
- 价格达到目标时会自动发送通知

### 3. 管理商品
- 点击商品查看详情
- 编辑商品信息
- 删除不需要的商品

### 4. 设置
- 启动/停止自动监控
- 查看监控状态
- 清除所有数据

## 反检测措施

1. **随机User-Agent**：使用多个不同的移动设备User-Agent
2. **随机延迟**：请求之间添加随机延迟（1-3秒）
3. **频率限制**：避免过于频繁的请求
4. **网络约束**：仅在WiFi下进行监控

## 配置说明

### 邮件通知配置
需要在 `NotificationHelper.kt` 中配置：
- QQ邮箱SMTP服务器：smtp.qq.com
- 端口：587
- 发送邮箱地址和授权码

### 微信通知配置
需要申请微信开放平台权限，集成微信SDK

## 权限说明

应用需要以下权限：
- INTERNET：网络访问
- POST_NOTIFICATIONS：发送通知
- WRITE_EXTERNAL_STORAGE：存储权限（仅用于Android 10以下）
